# Bound Web admission independently of CLI symmetry support

Protect the shared web launcher from anonymous clients and ordinary authenticated users exhausting other users' access, including on a private lab network or VPN. Web admission may reject symmetry orders exceeding a service resource budget before expensive validation, while the CLI retains its existing accepted symmetry orders; this deliberately narrows the Web acceptance promise in ADRs [0017](0017-support-point-groups-in-class-orientation.md) and [0018](0018-support-point-groups-in-axis-search.md) without redefining the shared scientific symmetry conventions.

Anonymous bootstrap uses an expiring, signed cookie with browser-bound CSRF, without reserving server-side session capacity. This avoids both anonymous pool exhaustion and repeated eviction of legitimate visitors sharing a lab network address. Authenticated sessions remain server-side and are never evicted to admit another visitor; when all 2,048 authenticated slots are occupied, new sign-ins receive a controlled, retryable capacity response. Existing login-attempt throttling is outside this change.

Both Web workflows accept Cn/Dn only up to n=32, alongside their existing T/O/I support; Axis Search still rejects C1. Reject larger orders before acquiring the global argument-validation lock or generating operators, explaining the Web limit and suggesting CLI use. Never silently reduce a submitted parameter. The limit is a conservative service policy, not a scientific limit: isolated local, cache-cleared D32 registry measurements were approximately 45 ms, excluding HTTP overhead and concurrent workloads.

Regression tests exercise the public HTTP session/login/logout and job-submission boundaries plus CLI argument parsing. They cover anonymous request floods, CSRF/cookie integrity and expiry, authenticated capacity preservation/recovery, accepted and rejected symmetry bounds and encodings, and unchanged CLI support beyond 32. The scope is these two availability findings, not a guarantee against arbitrary traffic floods or authenticated account abuse.
