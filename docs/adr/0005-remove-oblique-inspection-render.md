# Remove the Oblique Inspection Render

Keep only the Camera View Render as the static 3D artifact in each Class Result. The extra tilted surface does not represent the solved Class Camera Orientation and adds visual and conceptual noise. Class Results therefore use three columns: 2D class average, Matched Projection, and Camera View Render. Users inspect depth interactively through requested Interactive Class Volumes or generated ChimeraX cameras. Surface Level remains an adjustable presentation choice and does not affect camera matching.
