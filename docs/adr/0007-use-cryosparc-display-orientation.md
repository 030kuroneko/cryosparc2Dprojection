# Use CryoSPARC Display Orientation for static results

Static Class Results use the vertical orientation shown by the CryoSPARC UI as their display reference. The 2D Class Average, Matched Projection, and Camera View Render are normalized only at the rendering boundary; matching arrays, registered MRCS data, match scores, and Camera Metadata remain unchanged. Camera View Render PNGs contain only the centered surface, while the comparison figure retains its external column title and reports Surface Level through metadata and job logs.
