# Limit Interactive Class Volumes to requested classes

Register one original Rendering Map for CryoSPARC's integrated volume viewer and generate exact static Camera View Renders plus ChimeraX cameras for every processed class. Create rotated Interactive Class Volumes only for classes explicitly requested by Class Number, because CryoSPARC's public External Job API does not document a way to preset the integrated viewer camera and duplicating a full map for every class would multiply storage use.
